# SPlayer - WordPress Backend Music Player Plugin

**Version:** 1.1.2  
**GitHub Repository:** [https://github.com/ShirazuNagisa/splayer](https://github.com/ShirazuNagisa/splayer)  

---

## Overview

SPlayer is a **lightweight, elegant, and customizable WordPress music player plugin**, designed for blogs and personal websites.  
Key features:
- Minimal round disc UI
- Rounded frosted glass panel
- Backend playlist management
- Custom cover for each track
- Drag-and-snap disc
- Smooth expand/collapse animation
- GitHub auto-update support

---

## Frontend Features

### 1. Round Disc
- Default position: bottom-right of the page
- Rotates when playing, stops when paused
- Draggable and snaps to edges
- Adaptive panel direction:
  - Disc on left → panel opens on the right
  - Disc on right → panel opens on the left

### 2. Expandable Playback Panel
- Rounded corners + semi-transparent frosted glass
- Shows cover, title, and control buttons
- Playback modes: loop / shuffle
- Smooth animation, non-intrusive to page view

### 3. Playlist and Cover Support
- Each track can have a custom cover
- Playlist editable in backend
- Add/remove tracks, update front-end dynamically

---

## Backend Features

- Graphical playlist management
- Set title, audio URL, and cover for each track
- Changes reflect immediately on front-end
- Safe backend asset loading
- GitHub auto-update support

---

## Installation & Usage

1. Download the plugin ZIP
2. Upload to `/wp-content/plugins/`
3. Enable the plugin in WordPress admin
4. Add tracks and covers in the SPlayer menu
5. Front-end: round disc appears at bottom-right, click to expand panel

---

## Suitable Scenarios

- Blog background music
- Personal portfolio sites
- Small music sharing websites
- Any WordPress site requiring a lightweight music player
