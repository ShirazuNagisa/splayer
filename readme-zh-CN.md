# SPlayer - WordPress 后台音乐播放器插件

**版本：1.1.2**  
**GitHub 仓库：** [https://github.com/ShirazuNagisa/splayer](https://github.com/ShirazuNagisa/splayer)  

---

## 一、概述

SPlayer 是一款 **轻量、简洁、可自定义的 WordPress 音乐播放器插件**，专为博客和个人网站设计。  
插件特点：
- 极简圆形唱片 UI
- 展开窗圆角磨砂玻璃设计
- 后台图形化播放列表管理
- 每首歌曲自定义封面
- 拖拽圆形唱片并吸附边缘
- 丝滑展开/收起动画
- GitHub 自动检查更新

---

## 二、前端功能

### 1. 圆形唱片
- 默认显示在页面右下角
- 播放时旋转，暂停时停止
- 可拖拽并吸附边缘
- 展开窗自适应方向：
  - 唱片在左 → 展开窗右侧
  - 唱片在右 → 展开窗左侧

### 2. 展开播放面板
- 圆角 + 半透明磨砂玻璃
- 显示当前封面、歌曲标题、控制按钮
- 播放模式：单曲循环 / 随机播放
- 动画平滑丝滑，不影响浏览体验

### 3. 播放列表和封面
- 每首歌可自定义封面
- 播放列表可在后台管理
- 支持添加、删除歌曲，实时更新前端

---

## 三、后台功能

- 图形化播放列表管理
- 每首歌可设置标题、音频 URL、封面 URL
- 保存后立即反映前端
- 安全加载后台资源，不影响其他插件
- 支持 GitHub 自动检测和安装更新

---

## 四、安装与使用

1. 下载插件 ZIP
2. 上传至 `/wp-content/plugins/`
3. 在后台插件页面启用
4. 在 SPlayer 后台菜单添加歌曲并保存
5. 前端页面右下角显示圆形唱片，点击展开播放面板

---

## 五、适用场景

- 博客背景音乐
- 个人作品展示网站
- 小型音乐分享站点
- 任意需要轻量音乐播放器的 WordPress 网站
