splayer 是一个轻量、极简、圆角风格的 WordPress 音乐播放器插件，支持可拖动的圆形唱片、展开的磨砂玻璃小窗、后台播放列表管理以及 GitHub 仓库更新检查与安装。

详见 README（各语言文件）

== Installation ==

1. 上传 `splayer` 文件夹到 `/wp-content/plugins/`。
2. 在 WordPress 后台插件页面激活插件。
3. 转到 “SPlayer” 管理页面，在播放列表中添加歌曲（标题、音频 URL、封面 URL 可选）。
4. 在需要的页面插入短代码 `[splayer]`。

== Frequently Asked Questions ==

= 如何添加歌曲? =
在后台的 SPlayer 管理页面点击“添加歌曲”，填写歌曲标题和音频 URL，保存。

= 如何检查 GitHub 更新? =
后台 -> SPlayer -> 更新 检查按钮将会请求 GitHub 仓库的 release 信息，若有新版本可下载并安装。


请在升级前备份 `splayer` 配置（可手动复制设置）。
