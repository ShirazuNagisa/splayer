# SPlayer - WordPress バックエンド音楽プレイヤープラグイン

**バージョン:** 1.1.5  
**GitHub リポジトリ:** [https://github.com/ShirazuNagisa/splayer](https://github.com/ShirazuNagisa/splayer)  

---

## 概要

SPlayer は、**軽量でシンプル、カスタマイズ可能な WordPress 音楽プレイヤープラグイン**です。  
ブログや個人サイト向けに設計されています。  

特徴：
- ミニマルな丸型ディスク UI
- 丸角のフロストグラスパネル
- バックエンドでのプレイリスト管理
- 各曲ごとのカスタムカバー
- ディスクのドラッグ＆スナップ
- 滑らかな展開/縮小アニメーション
- GitHub 自動更新対応

---

## フロントエンド機能

### 1. 丸型ディスク
- デフォルト位置：ページ右下
- 再生中は回転、停止時は停止
- ドラッグ可能でエッジに吸着
- 展開パネルの自動方向：
  - ディスク左側 → パネル右に展開
  - ディスク右側 → パネル左に展開

### 2. 展開プレイヤーパネル
- 丸角 + 半透明フロストグラス
- カバー、タイトル、操作ボタンを表示
- 再生モード：ループ / シャッフル
- 滑らかなアニメーションでページ表示に影響なし

### 3. プレイリストとカバー
- 各曲にカスタムカバー設定可能
- バックエンドで編集可能
- 曲の追加・削除、フロントエンドに即時反映

---

## バックエンド機能

- グラフィカルなプレイリスト管理
- 各曲のタイトル、音声 URL、カバー URL 設定
- 保存するとフロントエンドに即反映
- 安全な管理画面リソースロード
- GitHub 自動更新対応

---

## インストールと使用方法

1. プラグイン ZIP をダウンロード
2. `/wp-content/plugins/` にアップロード
3. WordPress 管理画面で有効化
4. SPlayer メニューで曲とカバーを追加・保存
5. フロントエンド：右下に丸型ディスクが表示、クリックでパネル展開
