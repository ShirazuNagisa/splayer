# SPlayer - WordPress 백엔드 뮤직 플레이어 플러그인

**버전:** 1.1.6  
**GitHub 저장소:** [https://github.com/ShirazuNagisa/splayer](https://github.com/ShirazuNagisa/splayer)  

---

## 개요

SPlayer 는 **경량, 심플, 커스터마이징 가능한 WordPress 뮤직 플레이어 플러그인**입니다.  
블로그 및 개인 웹사이트용으로 설계되었습니다.  

특징:
- 미니멀한 원형 디스크 UI
- 둥근 모서리의 프로스트 글라스 패널
- 백엔드에서 플레이리스트 관리
- 각 곡별 커스텀 커버 지원
- 디스크 드래그 및 스냅
- 부드러운 펼침/접기 애니메이션
- GitHub 자동 업데이트 지원

---

## 프론트엔드 기능

### 1. 원형 디스크
- 기본 위치: 페이지 오른쪽 하단
- 재생 시 회전, 정지 시 정지
- 드래그 가능, 가장자리에 스냅
- 패널 자동 방향:
  - 디스크 왼쪽 → 패널 오른쪽에 열림
  - 디스크 오른쪽 → 패널 왼쪽에 열림

### 2. 펼침 재생 패널
- 둥근 모서리 + 반투명 프로스트 글라스
- 커버, 제목, 컨트롤 버튼 표시
- 재생 모드: 반복 / 셔플
- 부드러운 애니메이션, 페이지 뷰 방해 없음

### 3. 플레이리스트 및 커버
- 각 곡별 커스텀 커버 설정 가능
- 백엔드에서 편집 가능
- 곡 추가/삭제 시 프론트엔드 즉시 반영

---

## 백엔드 기능

- 그래픽 기반 플레이리스트 관리
- 각 곡의 제목, 오디오 URL, 커버 URL 설정
- 저장 시 즉시 프론트엔드 반영
- 안전한 백엔드 리소스 로딩
- GitHub 자동 업데이트 지원

---

## 설치 및 사용

1. 플러그인 ZIP 다운로드
2. `/wp-content/plugins/`에 업로드
3. WordPress 관리자에서 활성화
4. SPlayer 메뉴에서 곡과 커버 추가 후 저장
5. 프론트엔드: 오른쪽 하단에 원형 디스크 표시, 클릭 시 패널 열림

---

## 적용 시나리오

- 블로그 배경 음악
- 개인 포트폴리오 사이트
- 소규모 음악 공유 사이트
- 경량 뮤직 플레이어가 필요한 모든 WordPress 사이트
